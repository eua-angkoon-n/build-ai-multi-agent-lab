Main color tone / design direction (docs/PROFILE.md, Tone section): minimal (มินิมอล) with soft earth tones (โทนเอิร์ทอ่อนๆ), modern 2025+ style design, UI should be easy on the eyes and uncluttered (สบายตา ไม่รก). Voice: friendly-yet-semi-professional, easy to read. Reference inspiration (rough direction only, not to copy exactly): https://21st.dev/@ncdai/components/hero-01 — intended for use in Lab 04 FE work.

**Why:** This is the approved aesthetic direction from the PROFILE interview (Lab 01), so all FE/UI work should stay consistent with minimal + soft earth tone rather than bold/saturated colors or dated design.

**How to apply:** When building or reviewing `src/pages/`, `src/layouts/`, `src/components/`, or styles, prefer soft earth-tone palettes (muted browns/beiges/greens/creams), minimal layouts, generous whitespace, and modern (2025+) UI conventions.
